# AI-Based-Resume-Screening-System
## Description
An intelligent resume screening system using NLP and Machine Learning to rank resumes according to job description similarity.

## Features
- Resume Parsing
- Skill Extraction
- Resume Ranking
- Match Score Generation
- Streamlit Web Interface

## Technologies Used
- Python
- Streamlit
- NLP
- Scikit-learn
- Sentence Transformers

## Run Project

```bash
streamlit run app.py
